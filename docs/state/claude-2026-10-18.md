### Bugs found and fixed (write-up: `docs/mistakes/tooling-proofs.md`, the 2026-10-18 entry)

- The first design missed the booking entirely (the reason for all of this).
  Then I got it wrong twice before obeying the board: first a hand-written copy
  of the window rule, then "a booking only blocks starts", which ignored the
  shared window.
- Older runner bugs:
  - task REPORTS were grepped as error lines, so "quota" / "401" in a summary
    read as a cut or as an auth failure
  - systemd's 5 h limit could kill a late run before WIP, cut or spend
  - a checkout with no git identity lost commits silently
- Scrutinize fixes:
  - a reset left the new window with no stop line
  - a between-task refusal for a booking still ran the handoff
  - give-backs spent `Budget`
  - the identity refusal spammed Discord every tick
  - the resume prompt and the end alert named the wrong cause
  - the reset checkpoint keyed on `pct > 0`
- Mine, caught by CI after a deploy: a bare `<sha>` in markdown broke the
  VitePress build (`md-raw-tags.test.js` exists for exactly that). I had run
  only two test files before that commit.
